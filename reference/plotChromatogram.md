# Plot an infusion profile chromatogram

Plot an averaged infusion profile chromatogram from a Binalysis object.

## Usage

``` r
plotChromatogram(x)

# S4 method for class 'Binalysis'
plotChromatogram(x)
```

## Arguments

- x:

  S4 object of class `Binalysis`
