# Plot sample total ion counts

Plot sample total ion counts.

## Usage

``` r
plotTIC(x, by = "injOrder", colour = "block")

# S4 method for class 'Binalysis'
plotTIC(x, by = "injOrder", colour = "block")
```

## Arguments

- x:

  S4 object of class Binalysis

- by:

  info column to plot against

- colour:

  info column to provide colour labels
