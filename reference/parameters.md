# Get and set spectral binning parameters

Get and set spectral binning parameters.

## Usage

``` r
scans(x)

scans(x) <- value

cls(x)

cls(x) <- value

# S4 method for class 'BinParameters'
scans(x)

# S4 method for class 'BinParameters'
scans(x) <- value

# S4 method for class 'BinParameters'
cls(x)

# S4 method for class 'BinParameters'
cls(x) <- value
```

## Arguments

- x:

  S4 object of class BinParameters

- value:

  parameter value to set
